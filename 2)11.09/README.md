# Практическая работа №2 — Node.js, npm и Vite (11.09)

Проект `my-react-lab/` — это шаблон **Vite + React**, структура файлов в точности
как в разборе из практической (шаг 5). Папки `node_modules/` и `dist/` в репозиторий
не попадают (см. `.gitignore`) — они создаются командами ниже.

## Шаги, которые выполняются на компьютере

| № | Что делаем | Команда | Ожидаемый результат |
|---|------------|---------|---------------------|
| 1 | Ставим Node.js LTS с nodejs.org (галочка *Add to PATH*), перезапускаем терминал/VS Code | — | — |
| 2 | Проверяем версии | `node -v` и `npm -v` | `v20.x` / `v22.x` и `10.x` |
| 3 | Создаём проект (в репозитории он уже создан) | `npm create vite@latest my-react-lab -- --template react` | папка `my-react-lab/` |
| 4 | Ставим зависимости | `cd my-react-lab` → `npm install` | появляются `node_modules/` и `package-lock.json` |
| 5 | Изучаем структуру и `package.json` | `code .` | см. таблицу ниже |
| 6 | Запускаем dev-сервер | `npm run dev` | `http://localhost:5173/` |
| 7 | Проверяем HMR: правим `<h1>` в `src/App.jsx`, сохраняем (Ctrl+S) | — | текст меняется без перезагрузки, счётчик не сбрасывается |
| 8 | Сборка и превью | `npm run build`, затем `npm run preview` | папка `dist/`, сервер на `http://localhost:4173/` |

> После `npm install` в папке появится `package-lock.json` — его нужно закоммитить
> (он фиксирует точные версии библиотек).

## Структура проекта

| Файл | Назначение |
|------|-----------|
| `index.html` | Точка входа: содержит `<div id="root">` и подключает `/src/main.jsx` |
| `package.json` | Манифест: зависимости, dev-пакеты и npm-скрипты |
| `package-lock.json` | Точная фиксация версий (создаётся при `npm install`) |
| `vite.config.js` | Конфиг сборщика Vite с плагином `@vitejs/plugin-react` |
| `.gitignore` | Исключает `node_modules/` и `dist/` из Git |
| `node_modules/` | Физические файлы библиотек (руками не правится) |
| `src/main.jsx` | Вызывает `createRoot` и монтирует `App` в HTML |
| `src/App.jsx` | Корневой React-компонент страницы |
| `src/App.css` | Стили корневого компонента |
| `src/index.css` | Глобальные стили документа |

## npm-скрипты

| Скрипт | Что делает |
|--------|-----------|
| `npm run dev` | dev-сервер с HMR |
| `npm run build` | компиляция и минификация в `dist/` |
| `npm run lint` | проверка кода линтером |
| `npm run preview` | локальный просмотр готового билда |

## Как работает HMR

Vite не перезагружает страницу целиком: он отправляет по WebSocket патч изменённого
модуля, и браузер подменяет только функцию рендера компонента. Поэтому состояние
(счётчик кликов) сохраняется.

## Для сдачи

Сделай скриншоты: вывод `node -v` / `npm -v`, страницу `localhost:5173` с текстом
«Окружение React настроено идеально!», вывод `npm run build`.
